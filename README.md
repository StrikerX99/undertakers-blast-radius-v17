# Undertakers Blast Radius V17.1

Extract this directory at the root of the team repository. Build from that directory on Linux/amd64.

```sh
docker build --platform linux/amd64 -t undertakers-v17-1 .
```

The selector reads the organizer's test catalog and independent patches from `/data` and emits a JSON worker plan for every patch. It uses the organizer's SQLGlot pin `eb11aec4be8cb2122afe713a4816662c3f0fb2fa`. The grids and test records shipped with the entry come from the team's measurements of that pristine program. The Docker build derives additional indexes from the same pin.

For eligible parser or generator changes, the selector compares active class members and table entries in the pinned and patched interpreters. Traces of the unchanged test suite identify which tests used those concrete dialect classes, expression handlers, callback keys or tokenizer inputs. It retains source readers, introspective consumers, and unresolved tests. For certain changes to optimizer methods it replays the patched optimizer rule on previously observed rule inputs, checking the complete resulting expression and options before dropping the expensive executor test. Verification is bounded by the potential reduction in the worker schedule.

A patch may edit both a shared SQL generator helper and a dialect callback that handles the same expression. For eligible edits, the selector follows every statically indexed helper reference to its named dispatch entry, includes the native readers of each affected cell, and checks both edited files in the same freshly imported program.

The scheduler compares one through eight workers. It assigns tests using their recorded durations and includes the two-second charge for each worker it starts. The separate comparison download has practice data, scoring scripts, worker plans and source fingerprints.
